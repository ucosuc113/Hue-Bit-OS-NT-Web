⚠️ Formatear sistema
Zona de operaciones destructivas. Úsala cuando el sistema tenga problemas por cache corrupto, apps duplicadas u otros errores de IndexedDB.
⚠️ ADVERTENCIA — Estas operaciones son irreversibles.
Se recomienda exportar tus archivos importantes antes de formatear.
Reparación rápida
Limpiar registro de apps (apps_meta)
Soluciona apps duplicadas tras actualizaciones. El Kernel las re-registra al reiniciar.
Limpiar preferencias (prefs)
Restablece configuración a valores por defecto.
Formato completo
Formatear todo el sistema
Elimina TODA la base de datos IndexedDB (webos_db) y recarga.
Se perderán TODOS los archivos, preferencias y datos.
Formatear solo sistema de archivos
Borra únicamente el store fs. Mantiene preferencias y apps.
💡 Tip: Si el sistema funciona bien, no necesitas formatear. Usa "Reparación rápida" primero para resolver problemas menores de caché.
